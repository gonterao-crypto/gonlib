
### realloc

[モジュールへ戻る][back]

引数

`void* ptr, size_t newsize`

戻り値

`void*`

これも、標準ライブラリのただのラッパーです。確保したメモリを拡張することができます。ptrには、既存のポインタを渡します。メモリをnewsizeバイト確保し、その先頭のポインタを返します。

> 既存のサイズより求めるサイズが大きく、後ろのメモリに空きがある場合はそのまま返し、内部のサイズを変更します。後ろ空きがない場合は新しくメモリを確保し、古いメモリからコピーします。確保できない場合は0、nullptrを返します。

> 注意：確保したポインタをそのまま代入する、以下のような書き方をすると、エラーで確保できなかった場合にnullptrが入り、freeができなくなってしまうため注意です。
```
void* p = gon::calloc(100, 1);
p = gon::realloc(p, 200);
if (p == nullptr) {
    // nullptrが入っているため解放できない。。。。
}
```
