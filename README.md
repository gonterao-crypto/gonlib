# gonライブラリ集

## 概要

C++のいくつかの機能が提供されるライブラリです。

## 必要な環境

* コンパイラ、Clang++ C++26にて確認

## 解説

### gonmemory

メモリを確保・解放・再確保ができます。標準ライブラリのただのラッパーです。

クラスのサイズ確保した場合はコンストラクタ・デストラクタが呼ばれませんのでご注意ください。

### gonbackvector

後ろに追記したり、後ろを削除することしかできない配列クラス[^1]を提供します。インデックスでのアクセス・back()でのアクセスも使えます。

### gonblock

データを固定幅のブロックとして管理するクラス[^1][^2]を提供します。

コンストラクタで指定された数が一つのブロックの大きさになります。

### gonutils

remove_refやmoveが提供されます

[^1]:イテレーターはまだ使えませんのでご注意ください。

[^2]:アクセスする際はブロックを気にせずお使いいただけます。また、基本的な操作はBackVectorと同じですが、back関数がないなどの違いがあります。
