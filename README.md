# gonライブラリ集

## 概要

C++のいくつかの機能が提供されるライブラリです。

## 必要な環境

* コンパイラ、Clang++ C++26[^2]にて確認

* ([gonmakev2](https://github.com/gonterao-crypto/gonmakev2/releases))

## 解説

### gonmemory

メモリを確保・解放・再確保ができます。標準ライブラリのただのラッパーです。

クラスのサイズ確保した場合はコンストラクタ・デストラクタが呼ばれませんのでご注意ください。

### gonbackvector

後ろに追記したり、後ろを削除することしかできない配列クラスを提供します。インデックスでのアクセス・back()でのアクセスも使えます。

### gonblock

データを固定幅のブロックとして管理するクラス[^1]を提供します。

コンストラクタで指定された数が一つのブロックの大きさになります。

### gonblocklength

基本はgonblockと同じものを提供します。

しかし、コンストラクタに指定する値がテンプレートの第二引数に移動したため、可変な値は入れられません。

また、クラス内部に配列を移動したため、少しだけメモリ効率が良くなったかもしれません。

### gonutils

remove_refやmoveが提供されます

### gonlerp

lerp関数が提供されます。ただそれだけです。

### gonbmp

bmp画像を操作するためのクラスを提供します。

### gonconsolecolor

エスケープシーケンスを使用した、コンソールへの色の出力を提供します。

### gonmath

vector2dクラスやsqrt関数が使えます。

---

詳しくはヘッダーの宣言をご覧ください。

注意：ヘッダーオンリーではありません。ご注意ください。

[^1]:アクセスする際はブロックを気にせずお使いいただけます。

[^2]:C++26でなくても動く可能性が大いにあります。
